# Mewgenics Archetypes

Небольшой фанатский сайт, посвящённый архетипам котов в **Mewgenics**.

## 📖 О проекте

Архетипы — это условное разделение котов на подклассы в зависимости от их способностей и стиля игры.
Они не являются официальной игровой механикой, но помогают определиться с направлением билда и эффективнее комбинировать способности.

## 🐱 Возможности

- Информация об архетипах и их особенностях.
- Описания способностей и характеристик.
- Интерактивные подсказки с изображениями и описаниями.
- Объяснения основных принципов создания билдов.

## 🛠️ Технологии

Сайт написан на чистых **HTML, CSS и JavaScript**, без фреймворков и сторонних библиотек.

## 🚀 Запуск

1. Склонируйте репозиторий или скачайте его архив.
2. Откройте `index.html` в браузере.
